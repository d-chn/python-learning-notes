01 / OBJECT MODEL

变量与对象引用

先分清“名字”和“东西”，很多 Python 疑问会迎刃而解。

一个变量究竟是什么？

变量名是对象的引用名称。= 通常让变量名绑定到右侧表达式得到的对象。
🏷️
生活类比：标签与盒子

对象是盒子，变量名是贴在盒子上的标签。把标签从旧盒子移到新盒子，不会改变旧盒子内部的东西。

a = [1, 2]
b = a             # 两个名字引用同一个列表
b.append(3)
print(a)          # [1, 2, 3]

b = [4, 5]        # b 重新绑定到新列表
print(a)          # [1, 2, 3]
print(b)          # [4, 5]

交互实验：共享引用与重新绑定

从 a = [1, 2]; b = a 开始，点按钮查看两个名字引用的数据。

提醒：对象身份与内容不同。两个列表即使内容相同，也可能是不同对象。可以用 is 判断是否为同一对象。

02 / MUTABILITY

可变性与元组

元组不可变，为什么元组里面的列表还能 append？

不可变约束的是谁？

元组的不可变性意味着：创建后不能增加、删除或替换元组元素所引用的对象；并不保证内部对象的状态不变。
🧺
生活类比：固定格子的储物柜

柜子第一个格子固定放了一个篮子。不能用新篮子替换原篮子，但可以往原篮子里放东西。元组是柜子，列表是篮子。

x = ([1, 2], "apple")
x[0].append(3)       # 合法：修改原列表
print(x)             # ([1, 2, 3], 'apple')

x[0] = [1, 2, 3]    # TypeError：替换元组元素

更换整个元组为什么合法？

x = (1, "apple")
y = x
x = (2, "apple")     # 合法：x 改为引用新元组
print(y)             # (1, 'apple')

x[0] = 3             # TypeError：修改元组内部元素

关键区别是：x = ... 重新绑定变量；x[0] = ... 尝试修改元组内部某个位置。两者根本不是同一层操作。

细节：即使元组自身不可变，包含列表的元组一般也不可哈希，不能直接作为字典键或集合成员。
03 / COLLECTIONS

四种容器类型

list、tuple、set、frozenset 的三个比较维度：顺序、重复、可变性。

类型有确定顺序允许重复可增删/替换
list是是是
tuple是是否
set否否是
frozenset否否否
🛒 list · 购物清单

商品有先后顺序、可重复购买、随时增删。

🏅 tuple · 已公布的名次记录

第一、第二、第三的位置固定，发布后不允许直接修改记录。

🍎 set · 水果品类名册

只关心有哪些种类，不关心顺序；同一种只登记一次，名册可以更新。

📜 frozenset · 定稿品类名册

只有互不重复的品类，而且不再允许增删。

a = ["apple", "banana", "apple"]
b = ("apple", "banana", "apple")
c = {"apple", "banana", "apple"}
d = frozenset({"apple", "banana", "apple"})

print(a[0])       # apple：可以按索引取值
print(len(c))     # 2：集合自动去重
c.add("cherry")  # set 可增删
# d.add("cherry") # AttributeError：frozenset 无 add
注意：{} 表示空字典，不是空集合；空集合要写 set()。集合元素必须可哈希，例如普通列表不能直接放入集合。
04 / OBJECT ORIENTATION

类与面向对象

数据和行为放在一起的目的，是让对象的职责更清晰。

类（Class）描述一类对象的属性与行为；对象（Object）是类的实例。
🚚
生活类比：一台输送机

输送机有长度、速度这样的数据，也有计算理论输送时间这样的行为。让输送机负责自己的计算，比让所有外部代码都去解析它的数据更有边界感。

class Conveyor:
    def __init__(self, length, speed):
        self.length = length
        self.speed = speed

    def travel_time(self):
        return self.length / self.speed

c = Conveyor(10, 2)
print(c.travel_time())  # 5.0

Python 与 Java 的“基本类型”区别

问题PythonJava

print(x.bit_length()) # 4

print(s.upper())    # HELLO

不要推导为“面向对象语言必须把所有类型做成类”。Java 也支持 OOP，却仍然有原始类型。Python 更统一地将值视为对象。

05 / LITERALS & TYPES

字面量与数值类型

“怎么写出一个值”和“这个值是什么对象”，属于两个不同层次。

什么叫字面量？

字面量（Literal）是直接写在源代码中、表示某个值的语法形式。
📝
生活类比：直接报数字与让人算出来

“10”是直接报答案；“5 + 5”是给出计算过程。最终都是十，但表达方式不同。

x = "apple"    # "apple" 是字符串字面量
n = 10         # 10 是整数字面量
m = 5 + 5      # 5 + 5 是表达式
z = 2j         # 虚数字面量；j 是虚数单位

为什么出现 1j？

complex 是 Python 的复数类型。例如 3 + 4j 具有实部 3 和虚部 4，可用于交流电、信号处理、频谱与控制系统等计算。

z = 3 + 4j
print(type(z))  # <class 'complex'>
print(z.real)   # 3.0
print(z.imag)   # 4.0
print(abs(z))   # 5.0
严格语法中，[1, 2]、(1, 2) 和 {"a": 1} 是容器显示式（display）；它们能直接构造值，但不能简单地与数字、字符串字面量等同。
06 / SCOPE

global 与变量作用域

为什么 global x = "fantastic" 会报错？

global x 声明函数中的名字 x 指向模块级作用域；赋值必须另写一条语句。
🏢
生活类比：办公室自己的白板与公司公共白板

函数内部默认可以有自己的局部名字。global x 相当于声明：“接下来我操作的是公司公共白板上的 x，而不是办公室自己的 x。”

x = "awesome"

def myfunc():
    global x
    x = "fantastic"

myfunc()
print("Python is " + x)  # Python is fantastic
global x = "fantastic" 是 SyntaxError；global 不是赋值语法。
x = "awesome"

def myfunc():
    x = "fantastic"  # 没有 global，创建局部名字
    print(x)          # fantastic

myfunc()
print(x)              # awesome

记忆：global 决定名字解析与赋值的作用域，= 负责绑定对象。日常代码中也可通过返回值传递结果，减少对全局变量的依赖。

07 / STRINGS

format() 与 f-string

两个占位符必须有足够的数据来填充。

✉️
生活类比：有空格的邀请函模板

“尊敬的___，请于___到场”。有两个空位就需要两个对应信息；只给一个，第二个空位自然填不了。

age = 63
height = 175
txt = "My name is Bill, I am {}, and I am {}"

# print(txt.format(age))  # IndexError：缺第二个参数
print(txt.format(age, height))
# My name is Bill, I am 63, and I am 175

三种常见方式

"{} {}".format(63, 175)                 # 顺序填充
"{1} {0}".format(175, 63)             # 指定位置
"{age} {height}".format(age=63, height=175) # 命名

age = 63
height = 175
print(f"Age={age}, Height={height}")  # f-string

在日常 Python 开发中，f-string 通常更简洁直观，花括号里还能写表达式，例如 f"明年 {age + 1} 岁"。

如果从网页复制了 **63** 这种 Markdown 加粗写法，Python 不会把它当作数字 63；代码中应直接写 63。
08 / BITWISE OPERATIONS

按位与、或、移位

把整数理解为一排二进制开关，运算就容易看懂。

为什么 5 & 3 = 1？

按位与 &：两位都是 1，结果才是 1。
🔌
生活类比：双开关条件

一盏灯必须同时满足“电源打开”和“安全门关闭”等两个条件才亮。按位与在每个二进制位上分别做这样的“同时满足”判断。

x = 5         # 0101
x &= 3        # 0011  →  0001
print(x)      # 1

print(5 | 3)  # 7：按位或
print(5 << 1) # 10：左移一位

为什么 5 >> 3 = 0？

右移三位时，右边移出的二进制位被丢弃。对非负整数，相当于除以 2 ** 3 后向下取整：5 // 8 = 0。

x = 5         # 00000101
x >>= 3       # 00000000
print(x)      # 0

print(5 >> 1)  # 2
print(5 >> 2)  # 1
print(5 >> 3)  # 0

交互实验：AND 与右移

对于整数 n，Python 中 n >> k 等价于 n // (2 ** k)。负数也按向下取整规则工作，例如 -5 >> 1 == -3。

09 / XOR

异或 XOR

相同为 0，不同为 1；对同一个值异或两次，会恢复原状。

按位异或 ^：每个二进制位上，两个值不同时输出 1，相同时输出 0。
ABA XOR B
000
011
101
110
💡
生活类比：一个可翻转的开关

把异或的第二个数看成“翻转指令”：位是 0 就保持原样，位是 1 就翻转。对同一位连续翻转两次，会回到起点。

x = 5           # 0101
x ^= 3          # 0011 → 0110
print(x)        # 6
x ^= 3
print(x)        # 5：恢复原值

print(2 ^ 3)    # 1：不是乘方！
print(2 ** 3)   # 8：乘方

交互实验：观察不同的二进制位

为什么能找出只出现一次的数字？

因为 A ^ A = 0 且 A ^ 0 = A。若其他数字恰好各出现两次，就能两两抵消。

numbers = [4, 1, 2, 1, 2]
result = 0
for n in numbers:
    result ^= n
print(result)  # 4
异或并不是安全的加密方案；单纯对数据与固定值做 XOR 很容易被还原。另外，对 set 使用 ^ 表示对称差集，即只在其中一个集合出现的元素。
10 / COPYING & REFERENCES

列表复制与浅拷贝

复制的是“书架”，还是连书架上的书都一起复制？

三个动作，看起来相似，本质不同

b = a 没有复制列表；a.copy()、list(a)、a[:] 创建新外层列表，但都属于浅拷贝。
📚
生活类比：书架和书

普通赋值：两人使用同一个书架；浅拷贝：有两个不同的书架，但架上仍指向同一批书；深拷贝：通常连架上的书也另复制一份。

普通赋值b = a两个变量 → 同一个外层列表；a is b 为 True。
浅拷贝b = a.copy()两个变量 → 两个外层列表；嵌套子列表仍共享。
深拷贝b = copy.deepcopy(a)递归复制内部对象；部分不可变对象和特殊对象可能仍被共享。
a = [1, 2]
b = a
c = a.copy()
d = list(a)
e = a[:]

print(a is b)  # True
print(a is c)  # False
print(a is d)  # False
print(a is e)  # False
易错点：== 比较内容是否相等；is 判断是否同一个对象。内容相同不代表对象相同。

嵌套列表：为什么浅拷贝后还能相互影响？

a = [[1, 2], [3, 4]]
b = a.copy()

b[0].append(5)
print(a)  # [[1, 2, 5], [3, 4]]

b[0] = [9, 9]
print(a)  # [[1, 2, 5], [3, 4]]
print(b)  # [[9, 9], [3, 4]]

b[0].append(5) 改变的是共享的子列表；b[0] = [9, 9] 改变的是 b 外层列表的一个引用位置。

原外层列表 a↘共享的子列表 [1, 2]↗新外层列表 b
复制容器 ≠ 复制容器中的对象。先判断“修改的是哪一层”，再预测影响范围。
11 / WHY IMMUTABILITY

为什么元组不能修改、添加？

元组不是“功能少的列表”，而是在表达固定结构的数据值。

设计意图：让数据的结构稳定

📍
生活类比：传感器坐标 vs 行李队列

行李队列中的成员不断进出，因此使用 list；二维坐标由 x、y 两部分组成，作为一个完整的值更适合用 tuple。坐标发生变更时，可以产生新的坐标值，而不必原地改变旧值。

bags = ["Bag001", "Bag002"]
bags.append("Bag003")       # 队列在变化

position = (10, 20)       # 固定结构的坐标
# position[0] = 15        # TypeError
position = (15, 20)       # 合法：重新绑定新元组
避免共享数据被误改

元组的元素位置无法被直接替换，有助于提早暴露错误。

表达固定记录

如坐标、RGB、某些固定字段的返回结果。

可作为复合字典键

当所有元素都可哈希时，元组也可哈希。

降低状态变化复杂度

不必担忧其他代码原地改变元组的元素引用。

不可变 ≠ 不能创建新值

x = (1, 2, 3)
y = x + (4,)     # 创建新元组
print(x)        # (1, 2, 3)
print(y)        # (1, 2, 3, 4)

(4,) 中的逗号不可省略。还要记住：元组只保证自身结构不变，如果它引用一个 list，列表内容仍可以修改。

元组不是“深度冻结”的容器，也不意味着天然线程安全；如果字段很多、需要清晰命名，可以考虑 NamedTuple 或 dataclass。
12 / HASHABILITY

哈希与可哈希性

为什么字符串可以做字典键，而列表不可以？

第一性原理：查找依赖稳定的定位规则

可哈希对象必须有可用的哈希值，并遵守约定：哈希值在生命周期内保持稳定；两个相等的对象必须具有相同的哈希值。
📖
生活类比：图书馆检索编号

拿书名/编号计算定位信息，就不用从第一本开始逐个找。如果编号随意变动但索引不更新，查找会出问题。哈希值不是全球唯一的身份证号：不同键可能发生哈希冲突，字典还需要比较键是否相等。

字典键→哈希计算→候选存储位置→必要时比较相等性
devices = {
    (10, 20): "Conveyor A",
    (30, 40): "Scanner B"
}
print(devices[(10, 20)])  # Conveyor A

# devices[[10, 20]] = "X"  # TypeError

哪些对象可哈希？

类型可哈希？理解方式
int / float / str / bool是内置的不可变值
tuple有条件所有元素都必须可哈希
frozenset是（其元素需可哈希）冻结集合的成员可哈希
list / dict / set否这些内置可变容器不提供哈希
a = (1, "apple")
b = ([1, 2], "apple")
c = frozenset({"apple", "banana"})

print(hash(a))  # 返回一个整数
# print(hash(b))  # TypeError：内部 list 不可哈希
print(hash(c))  # 返回一个整数
不要把“可哈希”简单等同于“不可变”。自定义类的对象也可能根据身份可哈希；具体要看 __hash__ 和 __eq__ 的约定。哈希碰撞不表示两个键相等。

为什么这对开发有意义？

字典 dict 用可哈希键定位数据，集合 set 用哈希支持去重和成员判断。比如把处理过的行李编号放入集合，通常比扫描长列表更适合快速查找。

processed = {"Bag001", "Bag002"}
print("Bag001" in processed)  # True

# 平均情况下，set/dict 的查找接近 O(1)
# list 的成员查找通常是 O(n)

01 / 切片索引

输出是什么？

x = [10, 20, 30, 40, 50, 60]
print(x[0:5:2])
查看答案与原因

[10, 30, 50]。从索引 0 开始，每隔 2 个索引取一次，stop=5 不包含。不要把切片写成“先取几个，再跳几步”。

02 / 删除行为

输出是什么？

x = [7, 8, 7, 9]
a = x.pop(0)
x.remove(7)
print(a, x)
查看答案与原因

7 [8, 9]。pop(0) 根据索引删除并返回第一个 7；remove(7) 根据值删除剩下的第一个匹配项。它不会删除所有匹配值。

03 / 原地修改和返回值

输出是什么？

x = [2, 5, 1]
y = x.reverse()
print(x)
print(y)
查看答案与原因

[1, 5, 2]，然后是 None。reverse() 原地改变 x 的顺序，但返回 None；sort() 也有类似特点。

04 / 浅拷贝的另一种写法

输出是什么？

a = [[1], [2]]
b = list(a)
b[0].append(9)
print(a)
print(a is b)
查看答案与原因

[[1, 9], [2]]，然后是 False。list(a) 创建新外层列表，但其中的子列表是共享的；外层对象不同，内部仍会受影响。

05 / 迭代时删除

输出是什么？

x = [2, 4, 6, 8]
for n in x:
    if n < 6:
        x.remove(n)
print(x)
查看答案与原因

[4, 6, 8]。删掉 2 后，4 左移到索引 0，而迭代推进到索引 1，跳过了 4。通常不要在遍历原列表时直接删除其元素；可用列表推导式生成新列表。

# 更易理解的过滤写法
x = [2, 4, 6, 8]
